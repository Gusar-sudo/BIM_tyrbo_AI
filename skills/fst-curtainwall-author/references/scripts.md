# Скрипты `fst-curtainwall-author` (каталог, собран `fst-pipeline/scripts/scripts_catalog.py`)

Запуск в Revit — `horizun_execute_python` с `code_path`; вне Revit — `python -I` (с графикой — `python -P -E`). Новый скрипт записи — из шаблона `fst-curtainwall-author/scripts/_template_write.py`. После добавления скрипта — пересобрать каталог.

| Скрипт | Что делает | Аргументы / запуск |
|---|---|---|
| `_template_write.py` | ШАБЛОН скрипта записи в Revit (horizun_execute_python). Новый скрипт записи — копировать отсюда. Правила (lessons.md, разд. 2): проба = та же запись + откат; транзакции закрываются при любой ошибке; | Аргументы: dry_run (по умолчанию true) + свои. |
| `copy_families_from_doc.py` | ПРИМЕНЕНИЕ: перезагрузить семейства в АКТИВНЫЙ документ из другого открытого документа (напр. библиотеки): source_doc (заголовок), names [] или name_prefix; до/после — пересечения импостов с панелями, импосты без геометр | Аргументы: source_doc, names / name_prefix, out_json |
| `export_families.py` | Выгрузить семейства из АКТИВНОГО документа (тест) по id типоразмеров (из args-файлов загрузок) и по именам семейств: EditFamily -> SaveAs в out_dir -> Close без сохранения. Модель не меняется. Ход — в log_json построчно. | Аргументы: args_files (с items[].symbol_id), symbol_ids, family_names, out_dir, log_json |
| `gkl_walltype_mullions.py` | Типы стен «Глухое заполнение ГКЛ»: краевые и внутренние импосты типа -> вариант «глухой ГКЛ» той же ситуации. «М2 FSC21 примыкание к стене с однослойным остеклением левый» -> «М2 FSC21 примыкание к стене глухой ГКЛ левый | Аргументы: name_contains («Глухое заполнение ГКЛ»), dry_run. |
| `inventory_from_query.py` | Инвентаризация импостов Фристайл из ответа horizun_query_model (только чтение модели). Вход: JSON-ответ horizun_query_model по OST_CurtainWallMullions с include_types=true, | Запуск: |
| `library_load.py` | Перенос в рабочую копию библиотеки: загрузить все .rfa из src_dir (переопределить семейства, значения параметров типов НЕ перезаписывать), проверить: число импостов/панелей и предупреждения до/после, уплотнитель во всех | Аргументы: src_dir, commit |
| `load_rfas.py` | ПРИМЕНЕНИЕ: загрузить семейства из rfas (замена существующих, значения параметров не переписываются) | Аргументы: rfas [пути]. |
| `make_glass_names.py` | Чтение модели -> файл правок для set_type_params.py: ADSK_Наименование «Стекло N мм» у стеклянных панелей М2/М3 (N = «Толщина стекла»), пустая ADSK_Единица измерения -> «м2». Глухие (ГКЛ) и типы с «(М1)» пропускаются. | Аргументы: out_file |
| `open_doc.py` | Открыть и активировать документ (тестовый проект). Модели не меняет. | Аргументы: path |
| `rename_types.py` | Переименование типов (Element.Name) — у типов стен «Имя типа» через параметр только для чтения. Проверки: новое имя не занято другим типом того же класса; после записи имя перечитано; число стен каждого типа не изменилос | Аргументы: renames [[id, "новое имя"], ...], dry_run (true — всё откатывается). |
| `save_doc.py` | Сохранить активный документ на диск (doc.Save) и сообщить результат. Проверку файла делает Claude отдельно (дата/размер). | — |
| `save_doc_compact.py` | Сохранить активный документ НА ТО ЖЕ МЕСТО со сжатием (SaveAs Compact + перезапись) — убирает «мусор» после многократных перезагрузок семейств. Проверку файла (дата/размер) делает Claude отдельно. | — |
| `set_type_params.py` | Массовая запись параметров ТИПОВ (текст; число — для Double/Integer, без единиц, напр. FT_*_Расход) (импосты, витражи, панели) по имени типа — для правок ADSK, когда типизированная команда требует по записи на тип. Типы  | Аргументы: args_file {writes:[{key, param, value}], transaction_name}, dry_run |
