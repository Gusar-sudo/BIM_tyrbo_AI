# Архитектура библиотеки «Фристайл Технолоджи»

Источник: «freestyletech_instruktsiya_po_rabote_s_modelyami.docx» (v1.0, 2021), «bimlib-freestyletech-001-048.xlsx», альбомы М1–М3. Состояние на 26.10.2026: модели в Revit 2017, ФОП ADSK 2017.

## Состав (48 позиций bimlib)
| № | Что | Категория Revit | Комментарий |
|---|---|---|---|
| 1–19 | Витражи «Без разрезки»: М1 зажимной профиль ЦС; М2 стойка основная/широкая × одинарное/двойное/ЦС, 62 мм; М3 стойка стандартная/основная/узкая, нащельник омега × одинарное/двойное/ЦС, 72 мм | Стены (системный витраж) | один типоразмер; «настраивается из сборок» |
| 20 | Дверь витражная однопольная | Двери (панель витража) | 2 типа: левое/правое |
| 21 | Дверь витражная двупольная | Двери (панель витража) | регулируемые створки |
| 22–47 | Сборки импостов FSC: М2 — FSC21, FSC17, FSC18, FSC144, FSC139, FSC22; М3 — FSC01, FSC04, FSC05, FSC08, FSC09, FSC111; каждая с одно- и двухслойным остеклением | Импосты витража | для переноса набора импостов в проект |
| 48 | Шаблон RVT с раскладкой типов и спецификацией ГОСТ (лист «001 – Компоновочный лист») | — | спецификация витражей, дверей, сборок и деталей |

Размещение: витраж — командой «Стена»; дверь — открепить панель витража и заменить на дверь; новые типоразмеры — копированием витража с нужной сборкой.

## Имена
Действующий формат: `BIMLIB_Витраж_Без разрезки_Система М2_Стойка узкая_Двойное заполнение_62мм`, `BIMLIB_ДверьВитражнаяОднопольная_ФристайлТехнолоджи`, `Сборка MODEL 2 FSC21 …`.
Типы витражей М2/М3 (решение пользователя 09.11.2026): вариант = стойка + нащельник + заполнение.
- М2: «Стойка узкая» = FS.C-21 (нащельник FS.C-28 / FS.C-29), «Стойка обычная» = FS.C-139 (FS.C-112 / FS.C-113).
- М3: «Стойка обычная_Нащельник клипсовый» = FS.C-01 + FS.C-20 + клипса; «…_Нащельник омега» = FS.C-01 + FS.C-11 / FS.C-82 + заглушка FS.C-10; «…_Нащельник Т-образный» = FS.C-111 + FS.C-112 / FS.C-113; «Стойка узкая» = FS.C-09 (в альбоме FS.C-115 — вопрос производству).
- Отдельное семейство «стойка с нащельником» не делается: витраж — системное семейство, вариант выбирается типом стены; сечения — семействами профилей.
- Старые имена (основная/широкая/стандартная) → новые: `_bim\batches\M2_C\type_renames_2026-11-09.csv`; аргументы прошлых партий содержат старые имена. Переименование — `scripts\rename_types.py` (Element.Name; «Имя типа» через параметр только для чтения).
Метод fetchBIM требует «от общего к частному» — действующий формат этому уже соответствует (Бренд/библиотека → тип изделия → система → вариант). **Не переименовывать без решения человека**: имена используются в проектах проектировщиков. Новые позиции — в том же формате.

## Параметры (из инструкции)
Общие для всех: `ADSK_Наименование`, `ADSK_Код изделия`, `ADSK_Обозначение`, `ADSK_Завод-изготовитель` (= ФристайлТехнолоджи), `ADSK_Единица измерения` — тип; `ADSK_Масса`, `ADSK_Масса_Текст` — экземпляр.
Двери: `Высота ручки` (тип), `ADSK_Размер_Ширина`, `ADSK_Размер_Высота` (экз.), `Открывание внутрь`, `Угол открывания 90`, `Угол открывания 30` (экз., Да/Нет), `Ширина правой створки` (экз., двупольная), `Левая`/`Правая` (тип, Да/Нет).
Детали импостов (все — тип): `FT_Основание_Наименование`, `FT_Основание_Артикул`, `FT_Основание_Расход`; пары `_Артикул`/`_Расход` для Витраж, Нащельник, Рейка, Держатель, Заглушка, Уплотнитель; `FT_Клипса_Расход`.
Замечено: в инструкции встречаются имена с пробелом после префикса (`FT_ Нащельник_Расход`). Проверить в модели фактическое имя; при расхождении — это кандидат на исправление, но только через вопрос (переименование ломает спецификации у пользователей).

## Устройство рабочих копий Revit 2026 (на 06.11.2026)
Рабочие файлы: тест `_bim\work\2026\test_M2M3_seals.rvt`, библиотека `_bim\work\2026\BIMLIB_ВитражиДвери_ВнутренниеПерегородкиИДвериВитражные_ФристайлТехнолоджи.rvt`. Порядок: всё сначала в тесте → пробный прогон → подтверждение → тест → подтверждение → библиотека → сохранение и проверка файла. Скрипты партий — `_bim\batches\M2_C\`, журнал — `_bim\test\2026-10-28_M2M3_seals\findings.md`.

**Импосты.** Тип импоста (системное семейство) → параметр MULLION_PROFILE → профиль `BIMLIB_Профиль_<М2|М3>_<FSC>_<Положение>_ФристайлТехнолоджи` (Центральный/Боковой/Нижний…, Однослойный/Двухслойный/Цельностеклянный, Правый/Левый, Закрытый, ГлухойГКЛ, стекло + ГКЛ). Тело = собственные линии профиля; графика узла = вложенное `BIMLIB_ЭлементыУзлов_*`. Типы по ситуации: центральный, примыкание к стене правый/левый, к полу, к потолку, свободный край (Закрытый, широкая рейка FS.C-26/FS.C-158), угловой/Т/135°, ГКЛ. Тип стены задаёт импосты по краям; ГКЛ-типы назначаются вручную.
Фасад: крайние стойки на всю высоту, верхний/нижний профили упираются в них; средняя стойка упирается в верх/низ, ригель — в стойки.

**Панели.**
| Семейство | Что внутри |
|---|---|
| `BIMLIB_ПанельВитража_Однослойная_…` | стекло 5/6/8/10 типом, уплотнитель U5–U10 контуром по DWG, FT_Стекло_* формулой |
| `BIMLIB_ПанельВитража_Двухслойная_…` | то же ×2; цельностеклянные типы (Добавка −2,5); межрамные жалюзи `FT_Жалюзи` |
| `BIMLIB_ПанельВитража_Глухая_…` | ГКЛ 12,5 с двух сторон + утеплитель (`FT_Утеплитель_*`), Выступ 6 мм |
Размер стекла: `rounddown(Ширина + 2·FT_Стекло_Добавка + FT_Стекло_Поправка)`, Добавка 62 мм 10,5 / 72 мм 12,5 / ЦС −2,5; «Выступ сбоку» по толщине стекла 10,87/11,45/11,53/10,06 (паз = грань профиля − 3,5). Ширина панели = L между гранями импостов.

**Не сделано / открыто:** накладка над стыком ГКЛ; FSC05 и FS.C-09 — нет правил стекла в альбоме; FSC08 — уплотнитель B на держателе; 135° — только «левые», держатель жёстко под 135°; нет типов свободного края М2 FSC17 и примыкания к стене М3 FSC04; FS.C-07, FS.C-115 в модели нет; двери — не начаты.

## Правила стекла
`<проект>\_bim\catalog\glass_rules.csv`: формула вида `l = L + k` (L — расстояние между витражами) или `l = L1 + k1` (L1 — между столбами/стойками) для каждой пары соседних профилей и для вертикали. Проверка: для каждой панели модели найти пару левый/правый (верх/низ) импост → правило → сравнить расчётный размер стекла с параметром/геометрией панели с допуском 0,5 мм. Пара без правила — вопрос, не допущение.
