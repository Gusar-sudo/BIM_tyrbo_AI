# Скрипты `fst-visual-review` (каталог, собран `fst-pipeline/scripts/scripts_catalog.py`)

Запуск в Revit — `horizun_execute_python` с `code_path`; вне Revit — `python -I` (с графикой — `python -P -E`). Новый скрипт записи — из шаблона `fst-curtainwall-author/scripts/_template_write.py`. После добавления скрипта — пересобрать каталог.

| Скрипт | Что делает | Аргументы / запуск |
|---|---|---|
| `before_after_grid.py` | Лист «было / стало»: строки — before / after, колонки — набор картинок (по имени). Обрезает белые поля. py -P -E before_after_grid.py <dir> <out.png> "<title>" tag1=Подпись1 tag2=Подпись2 ... | — |
| `build_package.py` | Сборка пакета визуальной приёмки М2/М3: картинки -> pkg\img (JPG/PNG уменьшенные), data.json, package.sha256. config: {pkg_dir, types:[{tag,name,short,system,stand,cover,fill,center_ref,edge_ref,flex:{c3d,f3d,fac,plan},n | Запуск: py -P -E build_package.py <config.json> |
| `client_view_templates.py` | Шаблоны видов «для клиента» + примеры видов у импоста; keep=false — проба С ОТКАТОМ (картинки), keep=true — оставить. FT_Клиент_План_1-50 (Medium, скрытые линии, тонкий разрез импостов/панелей), FT_Клиент_Узел_1-2 (Fine) | Аргументы: mullion_type_like, out_dir, keep=false, plan_half_mm=1500, node_half_mm=90, cut_lw=1, px=1600 |
| `compose_left_right.py` | Пары «левый / правый» в НАЧАЛЕ стены (план, стена идёт слева направо, стекло справа от импоста). Проверено 14.11 по стенам библиотеки (край FSC21 «правый» в начале стены, зазор 3 мм): у вертикального импоста | — |
| `compose_pocket_angles.py` | Столб целиком: 3D-тело, графика узла и на каждой стороне со стеклом (в т.ч. под углом) — полоса стекла 8 мм с торцом по правилу 3 мм и точка отсчёта. py -P -E compose_pocket_angles.py <pocket.json> <items.json> <out.png> | — |
| `compose_pocket_scheme.py` | Схема «откуда считать 3 мм» у центральных столбов: настоящий паз (вложенная графика узла), 3D-тело профиля, полоса стекла 8 мм (пунктир — 10 мм), точка начала изменения паза, торец стекла по правилу 3 мм и сейчас. | — |
| `compose_pocket_sides.py` | Схема «откуда считать 3 мм» по сторонам прочих столбов: сторона поворачивается так, что стекло входит слева. Серое — паз (графика узла), красное — 3D-тело, голубое — стекло 8 мм (пунктир 10 мм), зелёное — точка отсчёта и | — |
| `compose_pocket_variants.py` | Варианты торца стекла у одной стороны столба (схемы рядом): паз, 3D-тело, стекло 8 мм до заданного торца, кратчайший зазор от углов стекла до паза (стрелка), заход стекла в паз — штриховка. | — |
| `node_palette_png.py` | Цветные варианты одного узла: заливки из сечения Revit (node_section_loops.py: алюминий/стекло/уплотнитель) + линии графики узла из curves JSON профиля (batches\color\curves). Варианты палитры — в JSON. | — |
| `node_section_loops.py` | Только чтение: горизонтальное сечение узла у импоста (стойка/столб + соседние панели) на высоте z_mm от низа стены. Режет все тела (с вложенными) плоскостью, отдаёт контуры в мм в координатах импоста (X — вдоль стены, Y  | Аргументы: wall (имя или id), mullion_type_like (подстрока имени типа/семейства), z_mm (по умолчанию 1000), radius_mm (150), out_json. |
| `overlap_report.py` | Локально: по сечениям (node_section_loops.py) — наложение стекла/уплотнителя на металл импоста: площадь, «глубина» (толщина наложения = 2 × число шагов эрозии до исчезновения), место; картинка: общий вид + крупно. | — |
| `sheet_bodies.py` | Листы проверки глазами: на каждый профиль — линии узла (серые), заливка (серо-голубая), контур нового 3D-тела (красный), пустоты тела (синие); проблемные из _report.json — рамка оранжевая. По N профилей на лист. | — |
| `sheet_pockets.py` | Лист: контуры столбов (probe_pocket.py) — графика узла (серая) и 3D-тело (красное), оси, сетка 10 мм. py -P -E sheet_pockets.py <pocket.json> <out.png> [--cols=4] [--lim=80] | — |
| `sheet_row.py` | Лист-строка из картинок: python sheet_row.py out.png "подпись1=путь1" "подпись2=путь2" ...  (каждая обрезается по рисунку) | — |
| `show_facade_side.py` | Показ «с какой стороны стекло относительно стрелок разворота»: стена заданного типа (как нарисована) и та же стена, перевёрнутая (Flip), план Fine; стрелка и подпись — сторона Wall.Orientation (там Revit рисует стрелки р | Аргументы: wall_type, out_dir, length_mm=1200, origin_mm=[x,y], scale=5, px=1600 |
| `trial_color_node.py` | Проба цвета на одном узле С ОТКАТОМ (группа транзакций RollBack): картинки «было» и «стало». Виды: план узла (Coarse / Medium / Fine) и 3D с секущим кубом (Скрытые линии / Тонированный / Реалистичный, Fine). | Аргументы: mullion_type_like, rfas [], materials {}, out_dir, half_len_mm (150), px (1400), scale (2) |
