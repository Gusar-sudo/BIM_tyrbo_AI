# Реестр параметров

Общие параметры нельзя создавать «на ходу»: другой GUID у того же имени ломает сводные спецификации у проектировщиков. Поэтому все параметры живут в одном реестре, и модель сверяется с ним.

## Реестр `_bim\params\registry.csv`
Колонки: `name; guid; data_type; instance_or_type; group; tooltip; owner (ADSK|FT); used_by (витраж|импост|дверь|…); status (действует|новый|устаревший); source`.
- Строки ADSK и FT_ заполняются **из модели** (фактические GUID читаются horizun_query_model / horizun_manage_parameters list_bindings), а не из памяти.
- Новые параметры (`status=новый`) — только из утверждённого ТЗ (`fst-tz-gate`), с источником.
- Имена — как в модели; опечатки в документах (пробел после `FT_`) не переносить.

## Проверка модели против реестра
1. `horizun_health`; документ — копия в `_bim\work\`.
2. Прочитать параметры типов/экземпляров нужных категорий (`horizun_query_model`, parameter_format full — там видны GUID/shared).
3. Отчёт: отсутствует / лишний / другой GUID / семейный вместо общего / не та группа или тип-экземпляр. Другой GUID при том же имени — **критично**.

## Добавление параметров
- Файл общих параметров (ФОП) проекта — один; путь хранится в реестре.
- Проект: `horizun_manage_parameters` operation `create_shared` или `horizun_bind_shared_param` (merge_existing_categories: true); семейство: `horizun_family_apply` `add_shared_params` с `spf_path`, `rfa_path`, `expected_revit_version`.
- Всегда dry-run → в визуальный пакет (таблица «какие параметры, куда, тип/экземпляр, группа») → «Принять» → применение → повторная проверка.
- Переименование и удаление действующих параметров — только строкой ТЗ с пометкой «ломает совместимость».

## Служебные параметры fetchBIM у Фристайл
Существующие ADSK/FT_ не переименовываются. Ограничения и проверки (по методологии) добавляются новыми параметрами с префиксом `FT_`: `FT_MIN_…`, `FT_MAX_…`, `FT_INC_…`, `FT_CHK_…`, `FT_Стекло_Ширина/Высота` — формулы и правила из `partition-family-author\references\partition-parameters.md` (раздел ограничений формул Revit).

## Данные
Только локальные файлы и модель через horizun.
