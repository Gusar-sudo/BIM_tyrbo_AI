# Требования «Фристайл Технолоджи» к моделям (F1–F6)

Источники: инструкция по работе с моделями (2021), таблица bimlib 001-048, альбомы М1–М3, решения от 26.10.2026.

## F1. Параметры ADSK (все модели)
| № | Проверка | Как |
|---|---|---|
| F1.1 | Есть `ADSK_Наименование`, `ADSK_Код изделия`, `ADSK_Обозначение`, `ADSK_Завод-изготовитель`, `ADSK_Единица измерения` (тип) | список параметров типа |
| F1.2 | Есть `ADSK_Масса`, `ADSK_Масса_Текст` (экземпляр) | список параметров экземпляра |
| F1.3 | `ADSK_Завод-изготовитель` одинаков во всей библиотеке и равен **`ФристайлТехнолоджи`** — решение пользователя 14.11.2026 (так в инструкции 2021 и в формулах семейств панелей; прежнее `ООО "Фристайл Технолоджи"` у импостов и витражей М2/М3 заменено) | значение |
| F1.4 | ADSK-параметры — общие (shared) с GUID из ФОП ADSK, а не семейные одноимённые | IsShared + GUID |
| F1.5 | Пустые ADSK-значения перечислены (часть заполняется после расчёта производства — это допустимо, но должно быть видно) | значения |
| F1.6 | `ADSK_Наименование` панелей М2/М3: стеклянные — «Стекло N мм» (N = «Толщина стекла»), единица «м2»; ГКЛ — «Панель глухая ГКЛ 12,5 мм с утеплителем»; М1 не проверять (решения 14.11) | значения типов панелей |

## F2. Детали импостов (сборки FSC)
| № | Проверка | Как |
|---|---|---|
| F2.1 | Для каждой детали есть пара `FT_<Деталь>_Артикул` / `FT_<Деталь>_Расход` (Основание, Витраж, Нащельник, Рейка, Держатель, Заглушка, Уплотнитель; Клипса — только расход) | параметры типа |
| F2.2 | Каждый артикул найден в `profiles.csv` | сверка |
| F2.3 | Расход > 0 там, где артикул заполнен; пустой артикул ↔ пустой расход | значения |
| F2.4 | Имена параметров без лишних пробелов (`FT_ Нащельник_Расход` — замечание, не исправлять без решения: ломает спецификации у пользователей) | regex `^FT_\S` |
| F2.5 | Состав сборки соответствует сопряжениям в альбоме (`mates`/`joins` для стойки) | сверка с profiles.csv |

## F3. Витражи
| № | Проверка | Как |
|---|---|---|
| F3.1 | Толщина/ширина системы по альбому (М2 — 62 мм в имени, «толщина перегородки 65 мм» в альбоме — расхождение уточнить вопросом) | тип стены |
| F3.2 | Импосты и панели витража — из библиотеки Фристайл, без чужих семейств | типы |
| F3.3 | Стекло по `check_glass.py` | results.csv |
| F3.4 | Варианты заполнения соответствуют альбому: стекло 5/6/8/10 мм; глухое: ГКЛ 12,5, ЛДСП/МДФ 8/10 мм, ≤ 25 кг/м² | типы панелей |
| F3.5 | ГКЛ: кусок ГКЛ ≤ листа 1100 × 3000 (`FT_ГКЛ_Больше_листа` = нет у всех панелей ГКЛ); у стен «…Глухое заполнение ГКЛ…» все импосты «… глухой ГКЛ»; на границе стекло/ГКЛ — «стекло + ГКЛ, ГКЛ слева/справа» нужной слойности (решения 14.11) | параметры панелей, типы импостов по стенам |
| F3.6 | Панели нулевого размера (CURTAIN_WALL_PANELS_WIDTH = 0) — норма для слитых ячеек сетки: не ошибка, в пересчёты не брать; список выводить как INFO | `curtain_zero_panels.py` |

## F4. Двери
| № | Проверка | Как |
|---|---|---|
| F4.1 | Категория «Двери», размещается как панель витража | категория, шаблон |
| F4.2 | Параметры из инструкции есть и работают (Высота ручки, ADSK_Размер_Ширина/Высота, Открывание внутрь, Угол 90/30, Левая/Правая, Ширина правой створки) | параметры + flex |
| F4.3 | Толщина полотна 40 мм для сторонних полотен (альбом М2) | размер |

## F5. Спецификация
| № | Проверка | Как |
|---|---|---|
| F5.1 | Шаблон спецификации ГОСТ из RVT (лист «001 – Компоновочный лист») собирает витражи, двери, сборки и детали | `horizun_get_schedule_data` |
| F5.2 | Количество деталей = длина импостов × расход (пересчёт `fst-spec-price`) | сравнение |
| F5.3 | «О_Ведомость стекла» = пересчёт `glass_calc.py` по толщинам: листов и м² (Ш × В стекла × слоёв) | сравнение |
| F5.4 | «О_Ведомость ГКЛ» = `gkl_pieces.py` (куски, м² ГКЛ); число листов 1100×2500/3000 — раскрой `gkl_cut.py` (карта PNG в пакет приёмки) | сравнение |

## F6. Готовность к bimlib
| № | Проверка | Как |
|---|---|---|
| F6.1 | Строка модели есть в таблице выгрузки bimlib, поля заполнены (см. `fst-bimlib-release`) | xlsx |
| F6.2 | Картинки модели есть в `models_pictures` с именами из таблицы | файлы |
| F6.3 | Версия Revit и ФОП в описании совпадают с фактом | описание vs модель |
