# Скрипты `fst-family-audit` (каталог, собран `fst-pipeline/scripts/scripts_catalog.py`)

Запуск в Revit — `horizun_execute_python` с `code_path`; вне Revit — `python -I` (с графикой — `python -P -E`). Новый скрипт записи — из шаблона `fst-curtainwall-author/scripts/_template_write.py`. После добавления скрипта — пересобрать каталог.

| Скрипт | Что делает | Аргументы / запуск |
|---|---|---|
| `analyze_after.py` | Аудит «после» по фактам collect_after.py (без Revit): F1 ADSK, F2 детали и артикулы, соответствие имени типа / наименования / профиля (система, одно-/двухслойный, левый/правый), панели, витражи, сверка теста с библиотеко | Запуск: python analyze_after.py facts_lib.json facts_test.json profiles.csv album_dir out_dir |
| `check_fill_rules.py` | Чтение: требования заполнения (fst-requirements F1.6, F3.5, F3.6) в документе: F1.6 — ADSK_Наименование/единица панелей М2/М3: стекло «Стекло N мм» (N = Толщина стекла), «м2»; ГКЛ — «Панель глухая ГКЛ 12,5 мм с утеплител | Аргументы: document_title (необязательно; иначе активный). |
| `check_glass.py` | Сверяет размеры стекла в модели с правилами альбомов Фристайл. Вход: | — |
| `collect_after.py` | Только чтение: факты для аудита «после» (М2/М3, без М1 и дверей) -> JSON. Типы импостов (профиль, ADSK, все FT_*), типы панелей витража (ADSK, FT_*, толщина), типы витражей (ADSK, назначенные | Аргументы: out_json |
| `curtain_zero_panels.py` | Чтение: стены-витражи с панелями нулевого размера — сетка (линии U/V, удалённые сегменты), панели по ячейкам (позиция вдоль стены, размер, нулевая ли) | Аргументы: нет. Документ — активный. |
