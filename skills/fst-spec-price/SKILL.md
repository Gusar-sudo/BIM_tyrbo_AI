# Спецификация и цена

Человек не пересчитывает цифры — значит спецификация должна сойтись с независимым расчётом **до** показа, а каждая цена — иметь источник.

## Порядок
1. `horizun_health`; документ — тестовый проект `_bim\work\` с размещёнными витражами (не исходник).
2. Выгрузить импосты: тип, длина, все `FT_*_Артикул`/`FT_*_Расход` → `_bim\spec\<дата>\mullions.csv` (через спецификацию `horizun_create_schedule` dry-run → подтверждение → `horizun_get_schedule_data`; или существующая спецификация ГОСТ из шаблона RVT, лист «001 – Компоновочный лист»).
3. Выгрузить итог ГОСТ-спецификации Revit по артикулам → `revit_spec.csv` (article; qty).
4. Пересчёт и сверка:
   ```
   py -P -E "<skill>\scripts\spec_calc.py" mullions.csv revit_spec.csv prices.csv
   ```
   (`-` вместо файла, если его нет). Результат: `spec_calc.csv`, `diff.csv`.
5. Каждый артикул → поиск в `_bim\catalog\profiles.csv`; не найден → FAIL (в отчёт аудита).
6. Итог для `fst-visual-review`: «пересчёт = Revit: да/нет; артикулов без каталога: n; без цены: n».

## Цены — только с источником
- Допустимые источники: Excel/DOCX прайса от производства; строка PDF, сверенная визуально по картинке страницы (указать «стр. N, сверено визуально»).
- **Сейчас (26.10.2026) цен в модель и расчёт не подставлять**: прайс только в PDF (таблица разваливается при извлечении), и нет таблицы соответствия обозначений альбома (`FS.C-21`) артикулам прайса (`ФСТ-xx`). Оба пункта — в `_bim\catalog\questions.md`.
- `prices.csv` собирается из подтверждённого источника: `article; unit; price_rub; source`, где `article` — в той же системе обозначений, что `FT_*_Артикул` в модели.
- Цены в прайсе зависят от покрытия (н/о, RAL 9006, RAL 7021 муар, анод — по запросу) — выбирать строку по покрытию, указанному в проекте; не указано → вопрос.

## Расхождения
- DIFF в сверке: сначала проверить единицы (п.м. vs шт.), затем неполные пары артикул/расход (скрипт печатает «ПРОБЛЕМА»), затем фильтры спецификации Revit.
- Неустранимое расхождение — в отчёт и на визуальную приёмку как вопрос, а не скрывать.

## Данные
Цены и расход — коммерческая информация производства: только локальные файлы, без сети и сторонних сервисов; на веб-страницу приёмки выносить только итоги, без прайса целиком.
