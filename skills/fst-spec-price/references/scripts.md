# Скрипты `fst-spec-price` (каталог, собран `fst-pipeline/scripts/scripts_catalog.py`)

Запуск в Revit — `horizun_execute_python` с `code_path`; вне Revit — `python -I` (с графикой — `python -P -E`). Новый скрипт записи — из шаблона `fst-curtainwall-author/scripts/_template_write.py`. После добавления скрипта — пересобрать каталог.

| Скрипт | Что делает | Аргументы / запуск |
|---|---|---|
| `gkl_cut.py` | Раскрой ГКЛ на листы (без Revit). Вход: CSV кусков от gkl_pieces.py (panel_id;wall_id;layer;w_mm;h_mm). Листы: ширина 1100, длина 2500 или 3000 (аргументы). Кусок ставится шириной поперёк листа, высотой вдоль (без поворо | Запуск: python -I gkl_cut.py pieces.csv out_prefix [sheet_w=1100] [lengths=2500,3000] [kerf_mm=0] |
| `gkl_pieces.py` | Чтение: куски ГКЛ всех панелей ГКЛ проекта -> CSV для раскроя (gkl_cut.py). Кусок = FT_Стекло_Ширина × FT_Стекло_Высота (ячейка + заход в паз), кусков на панель = FT_ГКЛ_Кусков (2 слоя). | Аргументы: out_csv. |
| `glass_calc.py` | Чтение: независимый пересчёт стекла М2/М3 по экземплярам панелей — площадь = FT_Стекло_Ширина × FT_Стекло_Высота × слоёв (FT_Стекло_Уплотнитель_Линий), по толщине («Толщина стекла»). | Аргументы: нет. Вывод: по толщине — листов, м². |
| `glass_sched_diff.py` | Чтение: какие панели со стеклом (пересчёт glass_calc) не попали в спецификацию schedule_name, и почему — тип, наименование, завод, стадия, группа, вариант конструкции | Аргументы: schedule_name |
| `spec_calc.py` | Независимый пересчёт деталей витражей Фристайл и сверка со спецификацией Revit. Вход (CSV, разделитель «;», UTF-8): | Запуск: |
| `spec_dump.py` | Только чтение: (1) все импосты витражей (тип, длина мм, все FT_*_Артикул/_Расход типа) -> mullions.csv; (2) ячейки тела спецификации (по имени) -> schedule_cells.csv (как показано в Revit). | Аргументы: out_dir, schedule_name, only_m23 (true) |
| `spec_from_cells.py` | Итог спецификации деталей по выгрузке ячеек (spec_dump.py -> schedule_cells.csv) -> revit_spec.csv (article;qty). Пары колонок находит по шапке: «Артикул», за которой идёт «Кол»/«Кол.» — так новые группы (Заглушка, Держа | Запуск: py -P -E spec_from_cells.py schedule_cells.csv revit_spec.csv |
