## 📖 About

**BIM_tyrbo_AI** is a knowledge base and methodology library for fast,
predictable creation of BIM models and BIM families. Designed so that an
**AI assistant can retrieve the right skill** on demand, while a human reads
it as a clear guide.

> 🎯 One skill = one structured `.md` with metadata, examples and validation.

---

## ✨ Inside

| Section | Purpose |
|---------|---------|
| 🧩 **Skills** | Step-by-step modeling & family creation skills |
| 👪 **Families** | Parametric BIM families and templates |
| 📐 **Methodologies** | Standards, LOD/LOI, naming rules |
| 🔗 **Workflows** | "family + methodology + script" bundles |
| 🤖 **AI-ready** | Metadata and catalog for RAG/LLM retrieval |
