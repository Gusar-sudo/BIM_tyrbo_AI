# Фристайл BIM — рабочие документы проекта (копия `_bim` без моделей)

Текстовые документы проекта BIM-библиотеки «Фристайл Технолоджи» (М1/М2/М3, витражные двери), синхронизируются из
`C:\Users\user\Desktop\Фристайл\_bim\` после каждой сохранённой партии работы. Модели `.rvt/.rfa` (200+ МБ) сюда не кладутся —
их снимки в `_bim\archive\` на рабочей машине.

- `docs/` — handoff.md (передача проекта), status, план, вопросы производству, changelog
- `audit/` — аудиты моделей (финальный М2/М3 — `audit/2026-11-20/M2M3_финал.md`)
- `review/decisions.csv` — все решения пользователя
- `test/findings.md` — журнал работ М2/М3
- `params/` — ФОП FT_ и реестр параметров
- `catalog/` — каталог профилей, правила стекла
- `spec/` — сверки спецификации, стекло, раскрой ГКЛ
- `plugin/` — список команд плагина Revit, проверки правил, сборка комплекта skills
