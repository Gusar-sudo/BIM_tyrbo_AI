11.11.2026 пользователь решил: вопрос «как проектировщику делать узлы без Claude» обсудить на финале работы с семействами (перед выпуском bimlib), сейчас ничего не делать.

Варианты, которые я предложил: (1) инструкция + образцы в библиотеке; (2) скрипты Dynamo Player («Угол», «Проём», «До подвесного потолка», «Проверить узлы») из моих horizun-скриптов; (3) своя вкладка «Фристайл» (pyRevit / C#). Мой совет: сейчас 1, следом 2, позже 3; узлы по максимуму делать готовыми типами.

12.11.2026 пользователь: «все скрипты потом разместим в плагине к Revit, чтоб это делалось автоматически». Путь выбран — плагин. В него войдут и скрипты расчёта, например `apply_posts_gap3.py` (заход стекла 3 мм у столбов, ставится после расстановки витражей) и поправки стекла. Сейчас скрипты лежат в `~\.claude\skills\fst-*\scripts`. В плагине `_bim\plugin\fst-bim` пока только копии skills. Плагин для Revit ещё не начат.

14.11.2026: список команд плагина ведётся в `_bim\plugin\revit_plugin_backlog.md`. Пользователь добавил команду «Ригель»: высота ригеля и заполнение ячеек — выбор проектировщика (не жёстко 2100 в типовых стенах).

**Why:** ручная сборка узла — 5–15 действий с риском ошибки (левый/правый, отступ стены B у FSC08 41,7 мм, лишний импост).
**How to apply:** при подготовке выпуска ([[fst-bimlib-release]]) напомнить и спросить выбор пути.
